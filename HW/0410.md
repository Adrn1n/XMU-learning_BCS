# Spike Sorting Report (Chung et al. 2017)
## Action Potential Principle
Neurons send signals by action potentials: $\text{Na}^+$ ions rush in (depolarization -> sharp positive spike), then $\text{K}^+$ ions rush out (repolarization).
This creates a quick voltage change recorded outside the cell as an "extracellular spike".

## Paper Summary
MountainSort is a fully automated algorithm.
It takes raw electrode signals, finds spikes, extracts waveforms, and clusters them into single-neuron groups.
No manual work needed. Accuracy matches or beats manual sorting.
Code + data: open on [GitHub](https://github.com/flatironinstitute/mountainlab-js) and [Mendeley](https://data.mendeley.com/research-data/?query=A%20fully%20automated%20approach%20to%20spike%20sorting) (tetrode + polymer probe datasets).

## Reproduction Steps
1. Download code & data
2. Run pipeline: filter noise -> detect spikes -> extract features -> ISO-CUT clustering -> check isolation
3. Test on tetrode and 16-channel probe data

# Key Results
- Found clean single-unit clusters (isolation >0.95)
- Matched manual sorting on real data
- Beat Kilosort and Spyking Circus on simulated data
- Fast enough for large recordings

## Neuron Signal Understanding
We learned: raw signals mix spikes from many neurons + noise.
MountainSort separates them automatically by waveform shape and timing, so we can study each neuron's firing clearly.
This links directly to action potential spikes for real brain network analysis.
